# 🔐 Password Manager

مدير كلمات مرور آمن مبني بـ **C# / .NET 8** يعمل من سطر الأوامر، يجمع في أداة واحدة:

- 🔑 **خزنة كلمات المرور** — احفظ بياناتك مشفّرة على جهازك (الموقع، اسم المستخدم، كلمة المرور، ملاحظات).
- 🎲 **مولد كلمات المرور** — تحكم كامل بالطول ونوع الأحرف، واستثناء الأحرف المتشابهة، مع حفظ مباشر لأي موقع.
- ⏱️ **رموز TOTP** — رموز المصادقة الثنائية المكونة من 6 أرقام التي تتجدد كل 30 ثانية، مع عدّاد تنازلي مباشر.

---

## ✨ المميزات

| الميزة | التفاصيل |
|---|---|
| **تشفير حقيقي** | كل الخزنة تُشفّر بـ **AES-256-GCM** (تشفير + مصادقة) |
| **اشتقاق مفتاح قوي** | **PBKDF2-SHA256** بـ 600,000 جولة (توصية OWASP) |
| **كلمة مرور رئيسية** | مفتاحك الوحيد لفك التشفير — لا يمكن فتح الخزنة بدونها |
| **مولد آمن** | يعتمد على `RandomNumberGenerator` (مصدر عشوائي آمن Cryptographically) |
| **TOTP قياسي** | تنفيذ RFC 6238 معتمد، يدعم SHA1 / SHA256 / SHA512 و 6–8 خانات |
| **رابط otpauth://** | الصق رابط الـ QR مباشرة وسيُقرأ تلقائياً (الاسم والخوارزمية والفترة) |
| **نسخ للحافظة** | نسخ كلمة المرور أو رمز TOTP بضغطة واحدة |
| **قوة الكلمة** | مؤشر تقريبي لقوة كل كلمة مرور (ضعيفة / متوسطة / قوية / قوية جداً) |
| **واجهة عربية** | قوائم وألوان واضحة بتصميم تفاعلي |

## 📦 المتطلبات

- **Windows** (النسخ للحافظة تستخدم `clip.exe`)
- **.NET SDK 8.0 أو أحدث** — من [dotnet.microsoft.com](https://dotnet.microsoft.com/download/dotnet/8.0)

## 🚀 التشغيل السريع

```powershell
# من داخل مجلد المشروع:
dotnet run --project src/PasswordManager
```

أو بشكل مباشر:

```powershell
dotnet build -c Release
.\src\PasswordManager\bin\Release\net8.0\pm.exe
```

> عند أول تشغيل ستحتاج إلى تعيين **كلمة مرور رئيسية** تُستخدم لتشفير كل بياناتك. احفظها جيداً — لا يمكن استرجاعها إن نسيتها.

### أين يُحفظ ملف الخزنة؟
```
%APPDATA%\PasswordManager\vault.dat
```
يمكنك تغيير المسار عبر:
- `pm.exe D:\path\to\my-vault.dat` (حجة سطر أوامر)، أو
- متغير البيئة `PM_VAULT_PATH`

## 🎮 الاستخدام

| الميزة | كيفية الاستخدام |
|---|---|
| **كلمات المرور** | إضافة / عرض / بحث / تعديل / حذف، ونسخ اسم المستخدم أو كلمة المرور للحافظة |
| **المولد** | حدد الطول والأحرف الكبيرة والصغيرة والأرقام والرموز، أو استثنِ الأحرف المتشابهة `I l 1 O 0`، ثم انسخ أو احفظ مباشرةً لموقع محدد |
| **TOTP** | أدخل المفتاح السري `Base32` (مثل `JBSWY3DPEHPK3PXP`) أو الصق رابط `otpauth://`، ثم اختر الخوارزمية والخانات والفترة، وعاين الرمز قبل الحفظ |
| **المراقبة المباشرة** | شاشة تعرض كل الحسابات مع الرمز الحالي والتالي وعدّاد التنازل، تتجدد تلقائياً كل نصف ثانية |
| **تغيير كلمة المرور** | من القائمة الرئيسية مع التحقق من كلمة المرور الحالية |
| **إعادة التعيين** | حذف الخزنة بالكامل مع تأكيد مزدوج |

## 🧪 الاختبار الذاتي

الأداة مزوّدة باختبارات ذاتية تتحقق من سلامة التشفير والمولد ورموز TOTP:

```powershell
pm.exe --selftest
```

تشمل الاختبارات:
- تشفير وفك AES-GCM + رفض المفتاح الخاطئ + دورة الخزنة الكاملة.
- صحة المولد (الطول، أنواع الأحرف، استثناء المتشابهة، العشوائية).
- **ناقلات RFC 6238 الرسمية** لـ SHA1 / SHA256 / SHA512 (أكواد معروفة مسبقاً).

## 🛠️ البناء للإصدار (ملف واحد)

```powershell
dotnet publish src/PasswordManager -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
# الناتج: src/PasswordManager/bin/Release/net8.0/win-x64/publish/pm.exe
```

## 🔒 كيف تعمل الخزنة؟

1. كلمة المرور الرئيسية تتحول إلى مفتاح 256-bit عبر `PBKDF2-SHA256` مع Salt عشوائي و 600,000 جولة.
2. محتوى الخزنة (كل كلمات المرور وحسابات TOTP) يُسلسل إلى JSON ثم يُشفّر بـ **AES-256-GCM** مع Nonce عشوائي.
3. الملف على القرص يحتوي فقط على: `salt`, `nonce`, `tag`, والبيانات المشفرة — **لا شيء نصي**.
