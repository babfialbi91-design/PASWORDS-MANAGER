# 🔐 Password Manager

مدير كلمات مرور آمن مبني بـ **C# / .NET 8** يجمع في أداة واحدة:

- 🔑 **خزنة كلمات المرور** — احفظ بياناتك مشفّرة على جهازك (الموقع، اسم المستخدم، كلمة المرور، ملاحظات).
- 🎲 **مولد كلمات المرور** — تحكم كامل بالطول ونوع الأحرف، واستثناء الأحرف المتشابهة، مع حفظ مباشر لأي موقع.
- ⏱️ **رموز TOTP** — رموز المصادقة الثنائية التي تتجدد كل 30 ثانية مع عدّاد تنازلي مباشر.

## 🖥️ واجهتان

| الواجهة | الوصف |
|---|---|
| **🪟 تطبيق ويندوز (WPF)** — الافتراضية | نافذة رسومية كاملة بواجهة **عربية RTL** وثيم داكن حديث: شريط جانبي، بطاقات، ألوان، دعم حقيقي للغة العربية |
| **⌨️ نسخة طرفية (Console)** | نفس الميزات عبر سطر الأوامر، مع اختبار ذاتي `pm --selftest` |

---

## ✨ المميزات

| الميزة | التفاصيل |
|---|---|
| **تشفير حقيقي** | كل الخزنة تُشفّر بـ **AES-256-GCM** (تشفير + مصادقة) |
| **اشتقاق مفتاح قوي** | **PBKDF2-SHA256** بـ 600,000 جولة (توصية OWASP) |
| **كلمة مرور رئيسية** | مفتاحك الوحيد لفك التشفير — لا يمكن فتح الخزنة بدونها |
| **مولد آمن** | يعتمد على `RandomNumberGenerator` (مصدر عشوائي آمن) |
| **TOTP قياسي** | تنفيذ RFC 6238 معتمد، يدعم SHA1 / SHA256 / SHA512 و 6–8 خانات |
| **رابط otpauth://** | الصق رابط الـ QR مباشرة وسيُقرأ تلقائياً (الاسم والخوارزمية والفترة) |
| **نسخ للحافظة** | نسخ كلمة المرور أو رمز TOTP بضغطة واحدة |
| **قوة الكلمة** | مؤشر لحظي لقوة كل كلمة مرور |
| **مزامنة تلقائية** | كل تغيير يُحفظ فوراً في الخزنة المشفرة |

## 📦 المتطلبات

- **Windows 10/11**
- **.NET Desktop Runtime 8.0** — من [dotnet.microsoft.com](https://dotnet.microsoft.com/download/dotnet/8.0)

## 🚀 التشغيل السريع

### واجهة الويندوز (المُوصى بها)
```powershell
run.bat
```
أو:
```powershell
dotnet run --project src/PasswordManager.App
```

### نسخة سطر الأوامر
```powershell
dotnet run --project src/PasswordManager
```

> عند أول تشغيل ستحتاج إلى تعيين **كلمة مرور رئيسية** تُستخدم لتشفير كل بياناتك. احفظها جيداً — لا يمكن استرجاعها إن نسيتها.

### أين يُحفظ ملف الخزنة؟
```
%APPDATA%\PasswordManager\vault.dat
```
يمكنك تغيير المسار عبر متغير البيئة `PM_VAULT_PATH` أو تمريره كحجة سطر أوامر.

## 🎮 واجهة الويندوز

| القسم | الوصف |
|---|---|
| **شاشة الدخول** | إنشاء كلمة مرور رئيسية (أول تشغيل) أو فتح الخزنة، مع مؤشر قوة حي وخيار إظهار/إخفاء |
| **كلمات المرور** | جدول قابل للبحث، تفاصيل المدخل المحدد، نسخ اسم المستخدم/كلمة المرور، إظهار/إخفاء، تعديل، حذف |
| **المولّد** | شريط طول، خانات أحرف كبيرة/صغيرة/أرقام/رموز، استثناء المتشابهة، توليد تلقائي حي مع قوة وانتروبيا، حفظ لموقع محدد |
| **رموز TOTP** | بطاقات لكل حساب تعرض الرمز الحالي والتالي مع شريط عدّاد تنازلي يتغير لونه للتحذير، نسخ، إضافة/حذف |
| **الإعدادات** | تغيير كلمة المرور الرئيسية، نسخ مسار الملف، إعادة تعيين الخزنة مع تأكيد |

## 🧪 الاختبار الذاتي

نسخة سطر الأوامر مزوّدة باختبارات تتحقق من التشفير والمولد ورموز TOTP:

```powershell
pm.exe --selftest
```

- تشفير وفك AES-GCM + رفض المفتاح الخاطئ + دورة الخزنة الكاملة.
- صحة المولد (الطول، أنواع الأحرف، استثناء المتشابهة، العشوائية).
- **ناقلات RFC 6238 الرسمية** لـ SHA1 / SHA256 / SHA512.

## 🛠️ البناء والنشر

```powershell
# بناء كامل الحل
dotnet build -c Release

# نسخة ويندوز مستقلة (ملف واحد)
dotnet publish src/PasswordManager.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
# الناتج: src/PasswordManager.App\bin\Release\net8.0-windows\win-x64\publish\PasswordManager.exe
```

## 🔒 كيف تعمل الخزنة؟

1. كلمة المرور الرئيسية تتحول إلى مفتاح 256-bit عبر `PBKDF2-SHA256` مع Salt عشوائي و 600,000 جولة.
2. محتوى الخزنة (كل كلمات المرور وحسابات TOTP) يُسلسل إلى JSON ثم يُشفّر بـ **AES-256-GCM** مع Nonce عشوائي.
3. الملف على القرص يحتوي فقط على: `salt`, `nonce`, `tag`, والبيانات المشفرة — **لا شيء نصي**.
